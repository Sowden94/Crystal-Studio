Crystal Studio is beta software under active development. Expect frequent updates, occasional bugs, and changes to supported workflows. Save projects regularly and retain original crystallographic files.

This release provides the online app and desktop packages for Mac (Apple silicon and Intel) and Windows x64. It supports CIF, XYZ, MOL/SDF, text-based PDF coordinate import, symmetry completion from CIF bond links, molecule selection, project saving, PNG/GIF/WebM exports, and a dark interface with a white workspace.

These initial packages are unsigned and the Mac packages are not notarized. Native-platform testing is still required before promoting a release. The release is created as a draft so the maintainer can verify all downloads before publishing. Updates are installed manually from GitHub Releases.

See docs/guide/limitations.md and THIRD-PARTY-NOTICES.md in the source tree.
