# Demonstration files

All structures in this folder are constructed, illustrative geometries. They are not experimental crystallographic data, refinements, or evidence of thermal motion.

- `cubane.crystalstudio`: a saved project for testing Open project without changing the original geometry.
- `cubane.xyz`: one idealised C8H8 molecule for exploring styles and export.
- `two-cubanes-and-water.xyz`: two identical connectivity groups plus a separate water molecule. Try deselecting a group, **Only**, **Show all**, and **Keep one of each**.
- `symmetry-demo.cif`: a constructed ethane example whose listed asymmetric unit contains C1 and three H atoms. The symmetry-coded bond completes C2H6. Its displacement tensors are invented solely to demonstrate the ellipsoid display.

These example files are included under the same GPLv3 terms as Crystal Studio.
