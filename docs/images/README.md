# Demonstration media

These images and looping animations were exported by Crystal Studio using illustrative structures. No unpublished research coordinates or reports are included.

- `crystal-studio.png`: screenshot of the current application interface.
- `cubane-monochrome.png`: ball-and-stick cubane, 25° rotation angle, depth fading at 45%.
- `depth-off.png`: the same view with depth fading disabled.
- `cubane-space-filling.png`: space-filling cubane.
- `illustrative-ellipsoids.png`: cubane with deliberately constructed positive-definite displacement tensors. This demonstrates the ellipsoid display; these are not experimentally refined ADPs.
- `multiple-molecules.png`: the included two-cubanes-and-water example, all three connected groups shown.
- `selected-molecule.png`: the same example with only the first cubane selected. The view is recentered to fit the selected molecule.
- `cubane-rotation.gif`: ball-and-stick full-turn animation.
- `space-filling-rotation.gif`: space-filling full turn about X.
- `ellipsoid-rotation.gif`: full turn about X using the constructed ellipsoid example.
- MP4 copies were converted from the corresponding GIF exports for convenient viewing. They are not native MP4 app exports. The app's direct video format is WebM.

Each GIF repeats indefinitely. The new GIFs use 80 frames over four seconds; slower rotations are also available in the app.

The temporary example-loading controls used during media capture are not part of the shipped application. Images and animations themselves use the application renderer and export controls.

## Measurement examples

- `measurements-styled.png`: built-in synthetic cubane with distance and angle annotations, purple Arial text, green dotted measurement lines, and solid label connectors.
- `measurements-rotation.gif`: the same constructed geometry with measurements fading in near a bookmarked orientation; a four-second full turn with 80 frames and infinite repeat.

These are app exports from synthetic demonstration coordinates, not user research or experimental measurements.
